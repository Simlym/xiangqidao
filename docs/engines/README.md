# 用户提供的象棋引擎

象棋道只实现 UCI 协议适配，不包含、代下载、镜像或重新分发第三方引擎与评估权重。

## 选择方式

- PC：根据操作系统和 CPU 下载原生 UCI 引擎，在“设置 → 标准象棋引擎/揭棋引擎”选择程序或目录。
- Web / Android：下载兼容的 WASM UCI 引擎包，解压后在设置页选择整个目录。
- 自托管服务器：管理员自行把原生引擎放在服务器非公开目录，再填写绝对路径。

标准象棋与揭棋使用独立配置。揭棋引擎必须明确支持暗子局面和项目使用的扩展 FEN。

## 许可提醒

引擎程序和评估权重可能使用不同许可证。用户应从上游项目页面获取文件，并在商业场景下自行确认授权。
由用户提供文件并不会自动免除服务器运营方可能承担的许可义务。

推荐目录仅用于本机开发，不会进入发行包：

```text
local-engines/
├── xiangqi/<engine-id>/<version>/
└── jieqi/<engine-id>/<version>/
```

浏览器包格式见 [package-spec.md](package-spec.md)，推荐来源元数据见 [catalog.json](catalog.json)。
